# 论文解读

先调用 `fetch_paper`。它返回一篇还没写过的论文。没有新论文就停，并说明停了。用户指定了 arXiv 号时，把编号传给 `fetch_paper`。

`fetch_paper` 带 `peek: true` 时只返回标题、摘要和链接，不下载全文；不带 `peek` 才把 HTML 和 PDF 下载到 `papers/_source/`，返回里给出这两个路径。判方向用 peek，写正文前再取一次全文。优先读取 html，读到实验和结论为止。不要用网页获取去打开 arXiv，本机代理会让它失败。数字、公式和阈值只写文件里有的，附录里的也算。论文没报告的成本、消融或限制，写进「我的判断」，不要编成实验结果。

## 选题门槛

订阅的分组是 `cs.RO`、`cs.CV`、`cs.LG`、`cs.AI`、`cs.HC`，宽到会捞回大量非具身论文，所以动笔前先拿摘要过一遍这道判断。三条都满足才写。

1. **场景是具身的**：机器人在物理世界里感知、操作或移动，或者为这类系统造仿真、数据、硬件。纯 LLM、纯 NLP、纯图像识别、纯算法理论一律不写，标题里出现 robot 也不算数。
2. **有闭环的动作或环境**：策略学习、任务规划、运动控制、仿真环境、机器人数据，至少沾一项。只有感知模型、和操作没有闭环关系的，除非摘要明确说用在机器人任务上。
3. **摘要里能看到具体实验**：任务、数字、基线三者里至少有两样。只有演示视频或愿景陈述的跳过。

流程是 `fetch_paper` 带 `peek: true` 取一篇的摘要，过一遍上面三条：过了就用这篇的编号取全文，没过就记一行跳过、再 peek 下一篇。

不合方向的不要写解读，也不要在 `papers/YYYYMM/` 里留文件。按下面格式追加一行到 `papers/_skip/skipped.md`，然后立刻 peek 下一篇：

```
- <arxiv> <英文标题> — <一句理由>
```

插件读这个文件里的编号，下次选题会跳过它们。跳到合方向的那篇为止，不设篇数上限；`fetch_paper` 说窗口翻完了就停，把跳过的那几篇和理由报给用户。

用户点名指定了 arXiv 号时不做这道判断，点名就写。

## 文件

写完调用 `paper_save`：

- `title`：中文标题，卖冲突或场景，不用论文原名
- `slug`：方法名加一句短话，只用字母、数字、中文、下划线和连字符
- `arxiv`：编号，例如 `1706.03762`
- `topic`：仓库根目录 `topics.json` 里的一项，具身方向的一组：视觉语言动作模型、机器人操作与抓取、强化学习与运动控制、人形与移动操作、仿真与 Sim2Real、数据与数据引擎、评测与基准、世界模型与三维感知、具身推理与规划、硬件与系统、其他
- `date`：写作日期 `YYYY-MM-DD`，可省略
- `body`：标题以下的正文，不要自带 frontmatter，也不要重复写一级标题

`paper_save` 成功后，用你自己的 git 工具提交并推送到当前分支。提交说明：`docs: 新增论文解读 <标题>`。

## 正文顺序

小标题用纯文字，可以换说法，顺序不换。全篇 2500–4000 字，机制多、附录厚的可以更长；不要为了收尾再补一段总结。

1. **引子**：一个具体场景，三四段，把人放进问题里。场景必须来自论文的任务设定、数据集样例或失败现象，不要自己编。
2. **论文信息**：原标题、作者与机构、arXiv 链接、发表时间、代码或项目页（有就写）。
3. **问题背景**：先用一张表把这篇论文所在的那层东西厘清（概念、分层、术语各是什么、边界在哪）；再用一张表把已有路线分成两到三派，写清每派的做法和它卡住的地方；最后点出这些路线都没回答的那个问题。
4. **核心思想**：这套方法借了什么现成的框架或类比。一句话说清它把原来那个问题换成了什么问题。
5. **方法**：一节只讲一个机制，小标题写机制名，中英文对照，例如「机制一：笔记构建（Note Construction）」。每节先写它治的是哪种失败，再写怎么做的，公式用 `$...$`，论文给了伪代码或结构定义的可以放代码块。机制之间不许互相复述。
6. **实验**：设置单独一段，写清数据集、规模、基线和硬件；主结果一张表，消融一张表；然后写反常结果、参数敏感性、可视化结论。表格里的数字必须能在文件里找到。
7. **工程实现细节**：把能落地的部分单独拎出来，例如关键 prompt 的结构、阈值与超参、存储或部署选型、调用次数与延迟。只写论文或附录给了的，没给的放下一节。
8. **我的判断**：先写这个设计为什么站得住，再写论文没报的成本、没讨论的超参、和模型规模的关系，最后给几条能照做的建议，用两三句话收束。
9. **延伸阅读**（可选）：只从论文的相关工作里挑，一张表写清它和这篇的关系。论文没提的工作不要推荐。

## 句子

- 陈述为主，一段三到五句完整的话。不要一句一段抖机灵。
- 不用第一人称编经历。不写「我拿……去读」「读完我不太放心」这类假装个人体验的句子；判断集中在「我的判断」一节，前面几节只摆事实。
- 不用 emoji，不要「一句话总结」「结语」，不要「不得不说」「说白了」「换句话说」「值得注意的是」「让我们」这类填充，少用破折号和「不是……而是……」的对偶句。
- 专有名词第一次出现给英文原文，之后只用中文或只用缩写。
- 对比用表格，表格只放能对齐的数据，不要拿表格排版散文。
- 论文的主张和你的判断分成两截。论文没说的、你自己推出来的，一律写成判断，不写进实验。
- 图只说明它在讲什么，不贴原图。
