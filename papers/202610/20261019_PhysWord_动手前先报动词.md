# 动手前先报动词：16 个物理词把机器人隐式推理切成可复用阶段

## 引子

A4 纸平放在桌面上，边缘没有一处伸出桌沿。灵巧手把五指压上去，靠摩擦把纸推到桌边，等纸露出一截，再捏住、抬起、放进篮子。纸薄，捏得太靠边，接触面积不够，抬起来就从指间滑掉。

同一工位要连做三轮：放完一张，新纸出现，策略得从「放」切回「接近」。论文记了一个对照现象，只做隐式监督的版本放完后仍停在篮子附近上下抖动，不主动去够新纸，直到新纸被摆到特定位置才重新启动；把动作词接回推理链的版本在检测到新纸时把预测从 place 切回 approach，再开始下一轮。

两次失败指向同一件事。中间表示不能只是一段关于未来的连续向量，还得能被切成阶段、能被命名、能在阶段间切换。语言层的动作词提供命名，但 rotate 不说明转多快、接触面在哪、会不会打滑；纯隐变量有物理细节，却没有可复用的边界。论文把两者绑在同一个隐状态上。

PhysWord 让模型在出动作前先自回归报出未来几个时刻的动作词，每个词配一个隐状态，它同时被词标签和对应未来观测编码出的隐目标监督。仿真里它在 UniVTAC 上拿到 90.3%，在 LIBERO-Long 上 99.6%，两台真机平台四个任务平均 71.7%。

## 问题背景

「推理」在这条线上被几个词共用，先对齐各自所指。

| 概念 | 指什么 | 这篇里对应什么 |
|---|---|---|
| 视觉语言动作模型（Vision-Language-Action, VLA） | 把预训练视觉语言模型接到机器人动作输出上 | PhysWord 属于其中先推理后行动的一支 |
| 先推理后行动（reasoning-before-acting） | 出动作之前先生成一段中间表示 | 先自回归生成物理词，再去噪动作 |
| 物理词（Physical Word） | 原子动作词标签，加上承载未来视觉或触觉动态的隐状态 | pick_v、pick_t 这类词，每个未来时刻一对 |
| 隐式推理（latent reasoning） | 用连续隐状态承载中间推理，不落成自然语言 | 隐状态用余弦距离对齐未来观测的编码 |
| 世界动作模型（World Action Model, WAM） | 联合建模未来视频与动作序列 | Cosmos 分支预测未来 H 帧 |
| 动作块（action chunk） | 一次前向预测多步动作 | H=16，每 4 步插一词 |

已有路线大致三派。

| 路线 | 做法 | 卡在哪里 |
|---|---|---|
| 语言式推理 | 子任务预测、具身思维链（embodied chain-of-thought）、动作描述 | 语义清楚，物理粗糙，一个动词不携带接触位置与力度 |
| 未来视觉预测与 WAM | 预测未来帧，或联合建模视频与动作，把预测特征喂给动作头 | 动态表征丰富，但没有围绕共享动作语义组织，换场景就换一套隐表示 |
| 隐式推理 | 用紧凑隐状态表示未来物理动态 | 同一动作跨场景的隐状态会带上偶然视觉变化，缺可复用的原语边界 |

三派都回答了中间表示该放什么，没有回答这些表示按什么组织。论文把缺口写成一句提问：原子动作语义能不能把物理隐表示组织成可复用的推理原语。

## 核心思想

借来的第一件东西是语言模型的原生下一词预测接口。大模型做中间推理时本来就在生成 token，论文把这个接口挪到机器人上，让下一词变成下一段动作语义。第二件是动作分类学，早期操作研究已把动作拆成 pick、place、push 这类原子动词，论文直接沿用。

类比是：词是索引，隐状态是索引指向的内容。索引让同类内容落在同一抽屉里，内容保留这一场景的物理细节。原来的问题「怎么让隐式推理有结构」，被换成「让隐状态预测它所属的动作词，同时被未来观测拉住」。

替换给出三个可测后果：同类动作的隐状态靠拢，注意落在被操作物而非背景，阶段切换时预测的词跟着变。论文用表示分析、注意力可视化和长程任务分别对应。

## 方法

### 机制一：双分支共享注意力（Mixture-of-Transformers with Shared Attention）

治的失败是两种时间尺度打架：预测未来画面要长时序视频先验，出动作要语言与当前帧的细粒度对齐，塞进一个模型会互相挤。

PhysWord 用混合 Transformer（Mixture-of-Transformers, MoT）拆成两支。时间感知分支从 Cosmos-Predict2.5-2B 初始化，吃 t−4 到 t 的五帧头部视角，每帧 256×256，任务是预测未来 H 帧；推理与动作分支从 Qwen3-VL-2B 初始化，吃其余视角和语言指令，保留自适应分辨率。两个视觉编码器冻结，其余都训练。

两支各自保留 QKV 投影、FFN 和位置编码，投影后三者沿 token 维拼接做共享注意力，动作分支因此能读到视频分支想象出的场景演化。推理时 Cosmos 只做一步去噪，用全注意力取出预测特征并缓存 key 与 value。

触觉走 T3 编码器，从 FTP-1 初始化，每路观测提成 512 维。夹爪把两路拼成 1024 维、再与 t−1 拼成 2048 维 token，灵巧手把五指 2560 维池化到 2048 维，对齐词嵌入后两种末端能进同一配方。动作 token 排在物理词之后，用流匹配（flow matching）训练，再由共享 MLP 映射到统一动作空间：夹爪 14 维，灵巧手 56 维。

### 机制二：物理词表（Physical Word Vocabulary）

治的失败是隐表示没有共享语义。同一个 pick 用在瓶子和纸上，隐状态里混着背景、光照、物体外观这些偶然因素，跨场景不能复用。

论文按既有动作分类学定了 16 个标签。Movement 一类是 Approach、Move；Manipulation 一类是 Pick、Place、Flip、Rotate、Toggle、Open、Close、Push、Pull、Insert、Press、Click、Strike、Handover。每个标签带两个变体，视觉记作 _v，触觉记作 _t，写作 pick_v 和 pick_t。

两个变体从同一个 Qwen3-VL 词嵌入初始化，各自保留可训词表项。两个模态的目标落在不同隐空间，压到一个隐状态会互相冲突；共享初始化保住语义同源，独立词表项允许各自适配。纯视觉任务只生成 _v，加新词从对应预训练词嵌入初始化即可。

### 机制三：词标签与未来隐变量的联合监督（Joint Label–Latent Supervision）

治的失败是单一监督各缺一半。只对齐未来隐变量，表示没有语义边界；只预测动作词，表示里没有物理动态。

每个物理词把标签 w 与上下文隐状态 z 绑在一起，z 是预测 w 那个位置的输出隐状态，g 是对应的未来感官隐目标。词预测头把 z 映成词表 logits 并交叉熵监督 w；同一个 z 又用余弦距离拉向 g：

$L_{\mathrm{latent}} = 1 - \dfrac{z^{\top} g}{\lVert z\rVert_2 \lVert g\rVert_2 + \epsilon}$

四路损失相加：$L = L_{\mathrm{video}} + L_{\mathrm{CE}} + L_{\mathrm{latent}} + L_{\mathrm{act}}$。

隐目标分模态构造。视觉目标把未来头部视角图像送进 Qwen3-VL 视觉编码器，最后一层空间 token 池化成一个向量；触觉目标用 T3 编码器与同样的聚合，每个末端一个。未来观测只在训练时当目标。训练用分块 teacher forcing，推理按未来时刻自回归生成。

### 机制四：时间分块的物理词空间（Temporally Structured PhysWord Space）

治的失败是一个未来词会漏掉块内阶段转换。动作块内常常先接近再抓取，只报一个词等于把两段压成一段。

论文每隔 s 步预测一个词，在时域 H 上得到 K=H/s 个未来时刻。取 s=4、H=16，即 K=4，预测点落在 t+4、t+8、t+12、t+16。记 $z^{r,m}_{t,k}$ 为预测 t+ks 时刻物理词所用隐状态，r 取左右末端，m 取视觉或触觉，整个空间排成

$$\mathbf{Z}_t = \big[\, B^{\mathrm{L}}_{t,1}\; B^{\mathrm{R}}_{t,1}\; \cdots\; B^{\mathrm{L}}_{t,K}\; B^{\mathrm{R}}_{t,K} \,\big],\qquad B^{r}_{t,k} = \big(z^{r,\mathrm{v}}_{t,k},\; z^{r,\mathrm{t}}_{t,k}\big)$$

块按未来时刻排序，左末端在右末端之前，块内先视觉后触觉。块内全通，同一末端跨块因果，跨末端完全屏蔽，左右手看不到对方的词。第一个块用接在指令后的起始 token 引导：

```
[指令] [PW_start] | B_1^L | B_1^R | B_2^L | B_2^R | ... | B_K^L | B_K^R | 噪声动作 token × H
```

监督做了整块平移。k≥2 的块吃进 t+(k−1)s 时刻的词嵌入，输出隐状态承接 t+ks 时刻的标签与感官目标。一块的输出不只是预测，还是下一块的输入条件。

## 实验

### 设置

仿真用两个基准。UniVTAC 是视触觉接触密集操作，8 个任务，覆盖举升、分类、插入；LIBERO-Long 是 10 个长程任务。两边都每任务 50 条示范，按官方成功判据跑 3 轮、每轮 100 次 rollout，报告跨轮标准差。UniVTAC 每任务单独训一个策略，LIBERO-Long 联合训一个。

真机两台双臂平台。灵巧手那台是 Tianji Marvin 臂配两只 Sharpa Wave 手，每只 22 个主动自由度、五指都有触觉，任务是 Pick A4 Paper 和 Shuttlecock Insertion；夹爪那台是 i7 Pro 配 Xense 指尖触觉，任务是 Express Packing 与 Powered Screw Driving。每任务 100 条遥操作示范，PICO VR 操作，灵巧手加 Manus 手套采手指动作。每个方法跑 3 轮、每轮 30 次，桌上标 30 个位置轮流放物体。

### 消融

消融在 LIBERO-Long 与 UniVTAC 的瓶子入架、抬罐上做，固定 s=4。

| 变体 | 瓶子入架 | 抬罐 | LIBERO-Long |
|---|---|---|---|
| 仅视觉隐监督（OO） | 77 | 83 | 97.0 |
| 仅触觉隐监督（TT） | 73 | 65 | — |
| 仅动作词（WW） | 77 | 67 | 97.4 |
| 动作词 + 视觉隐监督（WO） | 87 | 89 | 99.6 |
| 动作词 + 触觉隐监督（WT） | 88 | 75 | — |
| 词序：触觉在前（WT→WO） | 90 | 90 | — |
| 词序：视觉在前（WO→WT，完整模型） | 93 | 95 | — |

三种单独监督都输给联合监督。词标签叠上视觉隐监督到 87/89，叠上触觉隐监督到 88/75，两个模态合起来、视觉词在前时到 93/95，这是完整模型。触觉在前的词序只有 90/90。

结构消融补了细节。抽掉实测触觉但保留触觉词，93/95 掉到 88/87；抽掉触觉词但保留实测触觉，掉到 87/89；两者都抽掉变成纯视觉，掉到 82/81。视觉隐目标换腕部视角是 85/83，头部加腕部一起用是 84/89，都不如头部单用。词嵌入改成随机初始化，从 90/90 掉到 84/86、从 93/95 掉到 89/90。先过一层可学 MLP 再对齐，瓶子入架 82、抬罐 78，触觉侧 80/70，都不如直接监督。

### 反常结果与参数敏感性

最反常的一条是时间感知分支的边际贡献很小。把 Cosmos 整支拿掉，所有视角直接进推理分支，物理词与两路监督都保留，UniVTAC 均值还有 86.4%，完整模型是 90.3%。一个 2B 视频分支在接触密集任务上换来的增益有限，与「世界模型是主力」的直觉不符。

第二条是触觉能被自己的预测替代。推理时把实测触觉换成先前预测的触觉隐变量，仿真均值 89%，只掉 1.3 个百分点；真机 Pick A4 Paper 从 93.3 掉到 90.0，Shuttlecock Insertion 从 60.0 掉到 56.7，各掉 3.3 个百分点。预测与事后抽取的真值隐变量比对，平均余弦相似度 0.9873，均方误差 0.0630。

第三条是间隔 s 的方向。论文试了 2、4、8、16 四档，H 固定 16，越密成功率越高，密集采样能抓到更细的阶段转换，选 4 是折中成功率与延迟。各档的具体成功率只画在图 3 右侧，正文没给数值。

真机上 Shuttlecock Insertion 60.0 对 56.7 只差 3.3 个百分点，每任务只跑 90 次试。

## 工程实现细节

预训练语料约 7,400 小时：人类手部 2,000+ 小时、DROID 350 小时、OpenNeoData 5,000+ 小时、Sharpa 100+ 小时，前两者无触觉。作者写明语料比 π0.5、N0-VTLA、T-Rex 用的更小，为排除数据量优势。清洗三道：视觉上剔全黑或近均匀帧、欠曝过曝、运动模糊、手与物体长时间离场的片段；动作上剔非法值与病态跳变，阈值按具身、动作空间、控制频率分组，用 1% 与 99% 分位做初值再人工调；去重按 PerAct 关键帧比腕部世界坐标，相差小于 2 cm 视为近重复，每组最多留两条。

标注走 GPT：把轨迹切成原子动作阶段并从词表打标，双臂左右独立标。抽 500 条人工校验，GPT 对人工标签的准确率 95%，错误主要是把停顿时的无意义动作误标成 click。真机另抽 2,000 帧比对，帧级准确率 90.5%。

训练：下游微调 100 个 epoch，AdamW 零权重衰减，全局 batch 48；基础学习率 1e-4，Cosmos 主干 2e-6，T3 编码器 5e-5，前 5% 步数线性预热后余弦降到零，BF16；预训练 2 个 epoch，每卡 batch 6。触觉目标的未来一侧加 stop-gradient，防止余弦损失把 T3 拉漂，T3 仍从当前触觉通路拿梯度。动作按训练集 1% 与 99% 分位归一化后裁到 [−1,1]，触觉 RGB 缩到 224×224。

推理：BF16、5 步去噪、s=4，单张 H100 上 4.9 Hz。真机用实时分块（real-time chunking, RTC），每块 16 个动作执行 8 个，边执行边异步预测下一块；仿真只执行第一个动作再重规划，触觉反馈用时序集成（temporal ensembling）合并同一时刻的预测。延迟从 205.4 ms 压到 94.6 ms，即 10.6 Hz，2.2 倍加速。分项：全量 CUDA Graph 捕获省 42.2 ms，保掩码的 FlashAttention 省 17.7 ms，GPU 侧 RGB 预处理省 13.8 ms，Qwen 侧融合 RMSNorm 省 15.2 ms，打包投影加融合 RoPE 省 8.2 ms，Cosmos 侧融合 RMSNorm 省 2.9 ms，会话元数据缓存省 3.7 ms，GPU 侧触觉预处理省 3.9 ms，位置元数据缓存省 1.5 ms，VAE 与 RGB 流重叠省 1.7 ms。这些优化不动权重与掩码，观测特征每题重算。

## 我的判断

设计站得住的地方在监督落点。词标签的梯度不经可学 MLP，直接打在生成该词的隐状态上，过 MLP 再对齐的两个变体（82/78、80/70）因此明显更差。词表只有 16 项，不承担表达能力，只承担索引功能，不会像开放式语言推理那样引入幻觉。

没报的有三处。MoT 两个 2B 主干在 H100 上 10.6 Hz，端侧部署数据一个字没有，蒸馏或换小主干的代价未知。7,400 小时语料的采集成本、GPT 标注成本、16 个标签覆盖不到的动词比例都没给。词表扩容只写了可从预训练词嵌入初始化，没做冷启动实验。

消融的空白也值得记。词表大小没扫，砍到一半或扩到两倍各自什么表现，是最该补的实验，它直接回答结构从哪来。词预测 90.5% 的参照是 GPT 标注，训练标签也来自 GPT，属于同源比对。

照做的建议：先复现词标签加直接隐状态对齐，时间分块放第二步；s 与 H 绑定，改 H 要重扫 s；触觉可按反馈路线先跑通，仿真 89%、真机各掉 3.3 个点，对没有触觉硬件的平台是可接受的起点。
